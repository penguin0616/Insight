# Insight

Created for [Don't Starve](https://www.klei.com/games/dont-starve/) and [Don't Starve Together](https://www.klei.com/games/dont-starve-together).

- [Insight on the DS Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2081254154)
- [Insight on the DST Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2189004162)

I made this source public to help people who might be trying to figure out how to make mods on their own. **Read the license for more information.**

## Goals

I wanted something like [Show Me](https://steamcommunity.com/sharedfiles/filedetails/?id=666155465), but with more *Insight* into the various game systems like health, damage, fuel, food, followers, naughtiness, etc.

My general rule of thumb is that if I can figure it manually with a calculator & the wiki, then I probably want it taken care of by Insight.

# Reporting issues

When reporting an issue, please provide as much relevant information as possible, such as:

- Crash logs (important!)
- Reproduction steps
- Screenshots
- Anything else you deem helpful

If your report is devoid of information, you are less likely to get a helpful response.
